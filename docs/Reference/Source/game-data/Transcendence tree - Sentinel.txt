The layout of the Transcendence tree is a bit weird.  This is the layout for the Sentinel tree.
If we look at the tree as a spreadsheet, it consists of 25 rows and 27 columns, but not all cells of the sheet contain a node.
Below I will map out the location of every node for each stat, like this: "Column:Row".  1:1 would be the top-left most node, and 28:25 would be the bottom-right most node.

# Cost
Nodes 1-4 = 1
Nodes 5-9 = 2
Nodes 10-16 = 3
Nodes 17-26 = 5
Nodes 27-41 = 8
Nodes 42-61 = 12
Nodes 62-86 = 18
Nodes 87-116 = 26
Nodes 117-156 = 38
Nodes 157-206 = 55
Nodes 207+ = 80

# Special Nodes
Uncommon (Big) nodes cost x3 the node price at that point
Ancient Sigils cost flat 30
Glyph Sockets(not implemented)

# Types
Common Nodes - Single bonus stat
Uncommon (Big) Nodes - Two different bonus stats
Ancient Sigils - No bonus stats, but special effect
Glyph Sockets(not implemented)
