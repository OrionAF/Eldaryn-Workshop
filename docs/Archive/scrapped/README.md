# Archive/scrapped — abandoned approaches

Work we stopped doing on purpose. Not superseded by a better version — judged
to be the wrong thing to be doing at all.

**Every file here must say why it was scrapped**, because the reasoning is
almost always more valuable than the work. A scrapped approach that looks
reasonable and carries no explanation invites someone to try it again.

## Contents

| Document | Scrapped | Why |
|---|---|---|
| `combat-power-reverse-engineering-ABANDONED.md` | 2026-07-28 | Reverse-engineering the game's Combat Power rating. The formula is under active rebalancing, so any derivation is a snapshot that decays into a confident wrong answer — and this one had already been used to argue against a combat rule the owner confirmed was correct. Replaced by our own build-power metric, defined by us and stable by construction. |

## The lesson worth carrying out of this folder

A well-fitted model of a moving target is **more** dangerous than no model,
because its precision is mistaken for authority. The Combat Power work
reproduced 124 observed profiles to 0.05% and was, for a while, treated as the
most trustworthy thing in the repo.
