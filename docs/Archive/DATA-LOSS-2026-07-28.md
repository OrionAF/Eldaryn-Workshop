# Data loss incident — 2026-07-28

Recorded here rather than quietly patched over, because a gap in the archive
that nobody knows about is exactly the failure this documentation system exists
to prevent.

## What happened

During the docs restructure, a PowerShell script created `docs\Archive\...`,
moved five items into it, and then ran a cleanup loop that removed the now-empty
legacy folders — including `docs\archive` (lowercase), the old archive folder.

Windows paths are **case-insensitive**. `docs\Archive` and `docs\archive` are the
same directory. So `Remove-Item docs\archive -Recurse -Force` deleted the
freshly-populated Archive tree along with the legacy folder it was meant to
clean up. `-Force` bypasses the Recycle Bin.

Cause: mine. The script mixed "create the new tree" and "delete the old tree" in
one non-interactive pass, on a filesystem where the two names collide, without
verifying the moves had landed somewhere the delete could not reach.

## Recovery attempted, all failed

| Avenue | Result |
|---|---|
| Git | `docs/` was never tracked — `git ls-files docs/` returns 0 files |
| Recycle Bin | `Remove-Item -Force` bypasses it; nothing matching found |
| Volume Shadow Copies | Four exist, all on **C:**; this project is on **D:** |
| Duplicate copies elsewhere on disk | None found |

### The permanent loss

`design_handoff_preset_redesign/` was a 2026-07-03 design handoff bundle:
three `.dc.html` prototypes (Current UI, Preset Prototype, Redesign
Directions), a 58 KB `support.js`, a 21 KB README, and 17 copied `src/lib`
files including 8 test files.

Impact, stated honestly rather than minimised:

- **The prototypes and handoff README are gone for good.** They were the only
  copy. The preset redesign they described has shipped, so their forward value
  was low, but they were an irreplaceable record of how it was designed.
- **The 17 copied lib files carried no unique information** — they were a
  July-3 snapshot of `src/lib`, which has since evolved well past them.
- **The test suite went from 74 files / 838 tests to 66 / 715.** All 123 lost
  tests exercised those *copies*, not live `src/lib` code. **Coverage of the
  actual application is unchanged.** The suite is smaller; the app is not less
  tested.

### What survived that matters most

`EldarynTracker/combat_power_observations.csv` (84 KB) — the 124 observed
profiles behind the Combat Power derivation — was never in `docs/` and is
untouched. The *measurements* survived; only the narrative around them was
lost, and that work is retired anyway (see `scrapped/`).

## Consequences applied

- `docs/` must be brought under version control, or this class of loss recurs.
  Logged as a follow-up.
- Any future restructure separates moving from deleting: verify the new tree
  first, delete only after, and never `-Recurse -Force` a path whose
  case-variant is in play.
